📖 MINI TUTORIAL — COMO SE USA?

1. ABRIR PACK

Pulsa ABRIR CARPETA y selecciona una carpeta que tenga Animation.json, spritemap1.json y spritemap1.png. El editor detecta automaticamente el formato normal y el formato Adobe Animate / Better TA con simbolos anidados.

2. IMPORTAR PNG

Usa IMPORTAR PNGS para cargar frames individuales. Si abres solamente una imagen de spritemap sin sus JSON, el editor te pedira columnas y filas para cortarla en una cuadricula.

3. ARMAR ANIMACIONES

Selecciona una animacion en el panel derecho. Toca un frame para anadirlo o quitarlo de esa secuencia. Tambien puedes marcar varios y usar APLICAR FRAMES para meterlos en la animacion actual. AGREGAR ANIMACION crea una nueva. Tambien puedes cambiar FPS y LOOP.

4. SELECCIONAR + RENOMBRAR

Marca varios frames con las casillas. Luego usa RENOMBRAR SELECCIONADOS. Se respeta el orden en que los marcaste y se crea una secuencia con ese nombre.

5. VISUALIZAR

El cuadro grande muestra el frame actual. Pulsa VER para reproducir la animacion. Cambiar de animacion detiene la reproduccion y vuelve al primer frame. Con EDITOR DE UBICACION abres una pantalla completa para ajustar el offset de cada animacion.

6. EXPORTAR

Pulsa EXPORTAR para generar un ZIP con Animation.json + spritemap1.json + spritemap1.png. Puedes definir nombre, simbolo, posicion y FPS del personaje.
